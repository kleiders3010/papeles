# Papeles 1.0.1: release notes (draft, 2026-11-24)

Each line is a change committed on 2026-11-24 (1c70d37, 35d1119, ad97fe9, and the desktop Share commit).
Release waits on 1.0.0's Play approval.

## Play "What's new" (500 characters max each)

en-US:
Print and open in another app. Dark pages for night reading. Mark: pen colours and widths, highlighter colours, pick a mark to move, resize, edit or delete it, zoom with two fingers; highlights snap to whole words. Sign: zoom, a wider signature pad. Fill: see the filled pages before saving. Scan: see the cleaned page, Undo a removed page. Recent shows when you opened each file.

es-419:
Imprimir y abrir en otra app. Páginas oscuras para leer de noche. Marcar: colores y grosores de lápiz, colores de resaltador, elegir una marca para moverla, achicarla o agrandarla, editarla o borrarla, zoom con dos dedos; el resaltado toma palabras enteras. Firmar: zoom y un recuadro de firma más ancho. Completar: ver las páginas completadas antes de guardar. Escanear: ver la página limpia, Deshacer al quitar una página. Recientes muestra cuándo abriste cada archivo.

## GitHub release (Windows extras on top of the above)

- A PDF opened with Papeles, or dropped on its window, opens; photos dropped start Pictures to PDF.
- Ctrl+O, Ctrl+F, Page Up / Page Down, Ctrl + / Ctrl -.
- The installer offers Papeles in "Open with" for PDFs.
- Share copies the file (Ctrl+V pastes it into an email, a chat or a folder) and shows it in its folder.
- A PDF or photos sent from another app while you have unsaved work ask first (Android).
